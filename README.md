
# Afghan Future Hope

## Project overview

Afghan Future Hope is an educational information platform designed to help Afghan students discover learning resources, scholarship information, and educational pathways.

This project was developed for the WEB Technologies 1 (Front End) Endterm Project at Astana IT University.

## Project structure

```text
AfghanFutureHope/
├── index.html

├── css/
│   └── style.css
├── js/
│   ├── main.js
│   ├── opportunities-data.js
│   └── opportunities.js
└── README.md
```

## How to run

1. Open the AfghanFutureHope folder in Visual Studio Code.
2. Install the Live Server extension.
3. Open index.html.
4. Right-click and select "Open with Live Server".
5. Use the navigation bar to visit the Opportunities page.

An internet connection is needed for the external Bootstrap, jQuery, Google Fonts, and image resources.

## Main features

### Homepage
- Responsive navigation.
- Hero section and educational message.
- Mission cards.
- Educational story section.
- Three-step learning journey.
- FAQ accordion.
- Footer and back-to-top button.

### Opportunities page
- Ten JavaScript data objects.
- Dynamic opportunity cards.
- Search by title, provider, category, level, format, and description.
- Category and study-level filters.
- Alphabetical sorting.
- Saved opportunities using localStorage.
- Empty search state.
- Preparation checklist with calculated progress.
- Seven-field interest form.
- Inline JavaScript validation and success feedback.

## Validation rules

- Full name: at least two letters.
- Email: valid email format.
- Phone: 7–15 digits.
- Country: at least two letters.
- Study level: selection required.
- Area of interest: selection required.
- Motivation: at least 30 characters and no more than 500.
- Consent: required.

## Important note

The project is a front-end demonstration. Search, filtering, sorting, saved items, checklist progress, and form validation work in the browser. The interest form does not send information to a backend or submit an official scholarship application.
